# Царь Горы — сайт ТРП по «Богу старшей школы»

Сайт Discord-сервера «Царь Горы»: регистрация игроков, анкеты персонажа и чарёка, прокачка, галереи артов, проверка анкет анкетологами с чатом и панель ГМа.

Discord: https://discord.gg/4MFwMvgspf

Всё бесплатно: **GitHub Pages** показывает сайт, **Supabase** хранит аккаунты, анкеты и арты.
На всё уйдёт примерно 30 минут. Делай шаги по порядку.

---

## Что лежит в папке

| Файл | Зачем |
|---|---|
| `index.html` | сам сайт |
| `app/config.js` | **сюда вставляются ключи Supabase** (шаг 4) |
| `app/supabase-shim.js`, `app/auth.js` | подключение к базе и экран входа, не трогай |
| `supabase.sql` | скрипт, который создаёт базу и правила доступа (шаг 2) |
| `og.jpg`, `favicon.svg` | превью ссылки и иконка вкладки |
| `robots.txt`, `sitemap.xml` | для Google и Яндекса |

## Часть 1. База данных (Supabase)

**1. Создай проект.**
Зайди на **supabase.com** → *Start your project* → войди (удобнее всего через GitHub).
Нажми *New project*:
- Name: `goh-trp`
- Database Password: придумай и **сохрани** (понадобится редко, но лучше не терять)
- Region: ближайший к игрокам, например *Central EU (Frankfurt)*

Нажми *Create new project* и подожди 1–2 минуты.

**2. Создай таблицы.**
Слева *SQL Editor* → *New query*. Открой файл `supabase.sql` блокнотом, скопируй **весь** текст, вставь и нажми **Run**.
Внизу должно появиться *Success. No rows returned*. Красные слова `NOTICE` — это нормально.

**3. Настрой вход.**
Слева *Authentication*:
- *Sign In / Providers* (или *Providers*) → *Email* → выключи **Confirm email** → *Save*.
  Зачем: бесплатный Supabase отправляет всего несколько писем в час, и игроки не дождутся письма с подтверждением. Пароль от этого не становится слабее.
- *URL Configuration* → в **Site URL** вставь адрес сайта из шага 6 (например `https://твой-ник.github.io/goh-trp/`), в **Redirect URLs** добавь тот же адрес. Это можно сделать после шага 6.

**4. Скопируй ключи в сайт.**
Слева внизу *Project Settings* (шестерёнка) → *Data API* (или *API*):
- **Project URL** — адрес вида `https://abcdxyz.supabase.co`
- **anon public** key — длинная строка, начинается с `eyJ`

Открой `app/config.js` блокнотом и вставь их вместо `ВСТАВЬ_СЮДА_…` (кавычки оставь). Сохрани файл.

> Ключ `anon public` можно показывать: он публичный. Данные защищают правила из `supabase.sql`. Ключ **service_role** никуда не вставляй и никому не показывай.

## Часть 2. Сайт (GitHub Pages)

**5. Загрузи файлы.**
Зайди на **github.com**, зарегистрируйся. Справа сверху **+** → *New repository*:
- Repository name: `goh-trp`
- **Public** (иначе бесплатные Pages не работают)
- *Create repository*

На странице репозитория нажми *uploading an existing file* (или *Add file → Upload files*).
Перетащи **всё содержимое** этой папки, включая папку `app`. Внизу нажми **Commit changes**.

**6. Включи сайт.**
В репозитории: *Settings* → слева *Pages* → *Source*: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → *Save*.
Через 1–2 минуты сверху появится адрес: `https://твой-ник.github.io/goh-trp/`. Это ссылка на сайт.
Вернись к шагу 3 и впиши этот адрес в *URL Configuration*.

## Часть 3. Стань ГМом

**7.** Открой сайт → *Начать игру* → *Регистрация* → почта и пароль → укажи ник в Discord.

**8.** В Supabase → *SQL Editor* → *New query* вставь (подставь свою почту) и нажми *Run*:

```sql
insert into public.admins (user_id)
select id from auth.users where email = 'ТВОЯ_ПОЧТА@example.com'
on conflict do nothing;
```

**9.** Обнови сайт: появится вкладка **Панель ГМа**. Там:
- назначь анкетологов (сначала они должны зарегистрироваться);
- залей «Арты сайта», или включи кнопку «✎ Арты на странице» и меняй картинки прямо в рамках.

## Часть 4. Чтобы сайт находили в Google и Яндексе

**10. Впиши свой адрес** вместо `ТВОЙ-НИК` в трёх файлах: `index.html` (3 раза, в начале файла), `robots.txt`, `sitemap.xml`.
На GitHub: открой файл → карандаш ✏️ → исправь → *Commit changes*.

**11. Google:** **search.google.com/search-console** → *Добавить ресурс* → *Префикс URL* → вставь адрес сайта.
Способ подтверждения — *HTML-файл*: скачай файл от Google, загрузи его в репозиторий (как в шаге 5), нажми *Подтвердить*.
Потом слева *Файлы Sitemap* → впиши `sitemap.xml` → *Отправить*.

**12. Яндекс:** **webmaster.yandex.ru** → *Добавить сайт* → подтверди через *HTML-файл* так же.
Потом *Индексирование → Файлы Sitemap* → добавь `https://твой-ник.github.io/goh-trp/sitemap.xml`.

В поиске сайт появится через 1–4 недели. Быстрее помогут ссылки на сайт: описание Discord-сервера, Disboard, группы ВК и Telegram.

## Вход через Discord (по желанию)

1. **discord.com/developers/applications** → *New Application* → назови «Царь Горы».
2. *OAuth2* → скопируй **Client ID** и нажми *Reset Secret*, чтобы получить **Client Secret**.
3. Там же *Redirects* → *Add Redirect*: `https://ТВОЙ_ПРОЕКТ.supabase.co/auth/v1/callback` (твой Project URL + `/auth/v1/callback`) → *Save*.
4. Supabase → *Authentication* → *Sign In / Providers* → **Discord** → включи, вставь Client ID и Secret → *Save*.
5. В `app/config.js` поставь `DISCORD_LOGIN: true` и загрузи файл на GitHub заново.

## Как обновлять сайт

Загружай изменённые файлы в репозиторий поверх старых (*Add file → Upload files → Commit*). Через минуту изменения будут на сайте.

## Что важно знать

- **Пауза Supabase.** Если на сайт никто не заходит 7 дней, бесплатный проект засыпает. Включается кнопкой *Restore* в панели Supabase, данные не теряются.
- **Место.** Бесплатно примерно 1 ГБ под арты и 500 МБ под базу. Картинки сайт сжимает сам, а видео до 20 МБ съедают место быстрее всего.
- **Пароли.** Если игрок забыл пароль, кнопка «Забыл пароль» присылает письмо. На бесплатном плане писем немного в час, поэтому, если письмо не пришло, попроси подождать.
- **Защита.** Сервер сам проверяет права: игрок пишет только свою анкету и свой чат, SP и одобрение анкет может менять только ГМ или анкетолог, чужие чаты проверки никому не видны.
- Данные со старой версии на claude.ai сюда не переносятся: игроки регистрируются заново, а арты сайта нужно залить снова.
